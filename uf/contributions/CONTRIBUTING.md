# Contributing to UniversalFunctions

Thank you for your interest in contributing to UniversalFunctions!

## Before contributing

- Please review the existing code and documentation.
- Follow the established naming, documentation, and source-navigation conventions.
- Keep related APIs consistent, including function variants, type hints, and `.pyi` stubs.
- Test your changes before submitting them.

## Proposing changes

1. Fork this repository.
2. Create a branch in your fork for your proposed changes.
3. Implement and test your changes.
4. Open a pull request describing what you changed and why.

Bug reports, structural suggestions, documentation improvements, and new functionality are welcome.

All contributions are subject to review. Submitting a pull request does not guarantee that the proposed changes will be merged.

Thank you for helping the project grow!
